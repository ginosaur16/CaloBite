# CaloBite
A new app developed in SwiftUI applying the concepts of MVVM, Concurrency, and OOP.

<img width="368" height="732" alt="image" src="https://github.com/user-attachments/assets/559dbdec-5249-40b4-a8bb-3917ec1a998c" />

It's a Calorie Tracker with simple features but applying Swift Concurrency.

Main Features:
- Track Calorie Intake using the pre-generated food list or add custom food depending on the what was consumed.
- Export Tracker Log to .csv file for a spreadsheet style log.
- Customizable Information such as Calories and Macros goals.
